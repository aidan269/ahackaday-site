# Weekly Report Template

Save the report as `aeo-weekly-YYYY-MM-DD.md` in the working directory. Use this exact structure — do not improvise. The user reads these every week and consistency is what makes the report scannable.

---

```markdown
# AEO/GEO Weekly Report — YYYY-MM-DD

**Brand:** <user's brand>
**Pages audited this week:** <N>
**Average citation-worthiness score:** <N>/100  (last week: <N>/100, delta: <±N>)

---

## TL;DR

<3–5 bullets summarizing the most important takeaways from the week. The user should be able to read just this section and walk away with a clear sense of what to do.>

---

- **Target query:** "<phrase>"
- **Why it's underserved:** <one or two sentences>
- **Brand angle:** <one sentence>
- **Draft H1:** <title>
- **Draft TL;DR (40 words, citable):**
  > <40-word lead paragraph>

### Topic 2: ...

---

## Patterns and trends

<3–5 bullets calling out any cross-page patterns. Examples:
- "Three of five audited pages bury the answer below 300 words — adding a TL;DR block is the single highest-leverage fix this week."
- "No pages have visible 'last updated' dates. Suggest adding a publish + updated stamp template across the blog."
- "Competitor X is winning the 'how much does an audit cost' query with a 6-month-old post. Topic 3 is our response.">

---

## Open questions for the user

<Anything the skill could not resolve without the user's input. Examples:
- "Do you have internal data on average vulnerability counts per audit? If so, that becomes Topic 1 next week."
- "Confirm: is the goal to rank for 'smart contract audit' broadly, or specifically for 'DeFi protocol audit'? Affects topic queue prioritization.">
```

---

## Notes on producing the report

- Keep the TL;DR to bullets, not paragraphs. The user reads it on a phone.
- Do not include classic SEO recommendations (meta descriptions, internal link counts, keyword density) unless they directly affect AI citation behavior.
- Do not pad the topic queue. Five strong topics beats ten weak ones.
- Always include the "Open questions for the user" section even if it is empty — the user expects to see it.
- If this is the first weekly report (no previous one to compare to), drop the "last week / delta" line and replace with "(baseline week)."
